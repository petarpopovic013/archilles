# Archilles constitution

These documents define the product and engineering contract for the hackathon MVP:

- [PrD.md](PrD.md): user needs, requirements, priorities, and acceptance criteria.
- [Tech.MD](Tech.MD): system architecture, APIs, rule engine, and milestones.
